Flight Recorder
For controllers with the Flight Recorder plugin. Every job is stamped and its lines numbered, so the controller remembers where it got to. If the connection drops it lifts the tool and stops the spindle, and when you reconnect BearSender offers to carry on from that line. Its settings are in Settings, Flight recorder; the record and the event log are on the Job screen, in the Recorder panel. While this is on BearSender doesn't reset the controller when it connects.
⏯
Jobs and the resume
Hold at every M6: the job waits for Resume at each M6 in the file, also for the tool already loaded or when the controller ignores M6 ($341=4). Off, it holds only where the controller really changes tools.
Run lines after M30: grblHAL goes on reading after M2 or M30, with some modes reset. Off, the job ends at the first M2/M30 and the lines after it aren't sent. On, the file is sent whole and the Program panel says lines run after the program end.
Resume lift: the first move of a flight recorder resume goes up to this height, in mm below machine zero, unless the tool is already higher; then it crosses to the start of the line there. It never moves down.
